Инструкция менеджера и тимлида

1. Собрать команду

  1. Войдите в /admin своим email и паролем.
  2. Откройте «Моя команда». Введите имя, email и пароль нового менеджера (от 8 символов).
  3. Нажмите «Добавить». Менеджер появится в вашей команде и главной админке. Передайте ему адрес /admin и реквизиты входа выбранным способом. Приложение само не отправляет пароль по почте или в Telegram.
  4. Каждый менеджер получает свою реферальную ссылку. Партнёры, зарегистрированные по ней, относятся к нему.
  5. «Заблокировать» и «Сменить пароль» доступны для подчинённых. Смена пароля завершает старые сеансы. Для своего пароля используйте кнопку в шапке.
  6. Главный админ видит всех и назначает руководителей. Тимлид видит свою ветку команды; управлять чужими сотрудниками и повышать себя до главного админа нельзя.

Если партнёр пришёл без вашей ссылки

Для зарегистрированного партнёра без ответственного: «Партнёры» → «Привязать по email» → точный email, с которым он зарегистрировался → «Найти». Проверьте имя и email найденного аккаунта, выберите себя или своего менеджера и нажмите «Закрепить». Партнёр появится в команде и главной админке; новый аккаунт создавать не нужно.

Для перевода внутри команды: откройте карточку партнёра → «Ответственный менеджер» → выберите себя или активного сотрудника своей команды → «Сохранить».

Если партнёр уже закреплён за другой командой, перевод выполняет главный админ. Если поиск ничего не нашёл, проверьте именно email регистрации, попросите партнёра подтвердить, что аккаунт создан, либо проверьте существующее назначение через главного админа. Поиск не перебирает чужих партнёров по имени или Telegram.

Главный админ видит историю ручных назначений в карточке партнёра. Баланс и история аккаунта сохраняются. Записи профита, ранее внесённые менеджерами, остаются у их авторов. Новые реферальные ссылки дополнительно сохраняются на 30 дней в том же браузере; перенос на другое устройство этой функции не заменяет. Существующий аккаунт не перепривязывается просто от перехода по новой ссылке.

2. Ссылки выплат

В колонке «Ссылка на способ выплаты» виден действующий список и откуда он унаследован. Обычно это ссылки главного админа. Если главный админ задаёт отдельный список тимлиду, его команда наследует его, кроме сотрудников со своей индивидуальной настройкой.

Только главный админ меняет список через «Изменить / добавить». В карточке партнёра менеджер/тимлид выбирает разрешённую ссылку или «По умолчанию». Произвольную ссылку добавить через этот выбор нельзя.

3. Отчёт за сегодня

В «Моём отчёте» менеджер выбирает дату, заполняет количество сообщений Telegram и созданных групп и сохраняет. Профит вносится отдельными записями с Telegram партнёра и суммой.

В «Отчёте команды» по умолчанию выбран сегодняшний день по часовому поясу компании, обычно Москва. Видны статус сдачи отчёта, ручные показатели, профит и автоматические действия на сайте. Нажмите на количество действий или профит для деталей. Карточки показывают профит команды за день, неделю, месяц и всё время.

Расходы и чистый результат компании доступны только главному админу. Отчёты и профиты доступны внутри текущей команды.

4. Telegram-постбеки каждому партнёру

Это две разные настройки. «Telegram-боты» — служебные уведомления менеджеру о действиях партнёров. «Telegram-постбеки партнёра» в карточке — отдельный чат для регистраций, первых/повторных депозитов и отклонений, присланных трекером. Один бот может работать с несколькими партнёрами, у каждого — свой Chat ID.

Шаг 1. Создать бота

В Telegram откройте официальный @BotFather, отправьте /newbot и выполните подсказки. Полученный токен — секрет: он позволяет управлять ботом. Не отправляйте его в общий чат и не помещайте в URL трекера.

Для бота команды откройте «Telegram-боты», выберите свою запись и задайте токен и Chat ID служебного чата. Для отдельного бота партнёра токен можно указать в карточке партнёра.

Шаг 2. Подготовить чат и получить Chat ID

Личный чат: партнёр открывает бота и нажимает Start / отправляет /start. Бот не сможет первым написать пользователю, который ещё не начал диалог.

Группа: добавьте бота и отправьте /start@ИмяВашегоБота. Разрешите отправку сообщений. Права администратора группы нужны, если этого требуют её настройки; в канале нужны права публикации.

Сразу после сообщения откройте на своём устройстве:

https://api.telegram.org/bot<ТОКЕН>/getUpdates

Подставьте токен без угловых скобок. Найдите сообщение нужного чата, скопируйте message.chat.id; для поста канала — channel_post.chat.id. Не путайте с from.id, message_id или ID бота. У группы Chat ID обычно отрицательный, например -1001234567890.

При пустом result отправьте новое сообщение и повторите запрос. Если бот подключён к другому сервису через webhook или обновления забирает другой процесс, getUpdates может не работать/не показать сообщение. Проще создать отдельного бота. Не отключайте чужую интеграцию вслепую. Не публикуйте ссылку с токеном или скриншот; при утечке перевыпустите токен через BotFather.

Шаг 3. Сохранить настройки партнёра

  1. Откройте «Партнёры» → нужного партнёра → «Telegram-постбеки партнёра».
  2. Введите Chat ID именно его личного чата или группы.
  3. Для отдельного бота укажите токен. Пустое поле сохраняет прежний токен. Если отдельный токен никогда не задавался, используется бот менеджера/ближайшего тимлида, затем общий бот сайта из окружения.
  4. Для перехода на наследуемого бота отметьте «Убрать отдельного бота…» и сохраните. Служебный Chat ID менеджера не используется как чат партнёра — здесь он всегда задаётся отдельно.
  5. Выберите события: «Регистрация», «Первый депозит», «Повторный депозит», «Отклонение».
  6. Включите «Отправлять события в Telegram», нажмите «Сохранить настройки».
  7. Нажмите «Отправить тест по сохранённым настройкам». Проверьте сообщение с названием партнёра в нужном чате. Тест не меняет баланс или профит. Кнопка отправляет тест и при выключенных автоматических событиях.

Несохранённые значения не используются для теста. Для каждого следующего партнёра проверьте его Chat ID и сообщение теста.

Шаг 4. Подключить трекер или партнёрскую сеть

Раскройте «Ссылка для трекера и ключ» и скопируйте URL. У каждого партнёра отдельный адрес и секретный ключ. Токена Telegram-бота в ссылке нет.

Пример структуры, не готовая ссылка вашего сайта:

https://YOUR-DOMAIN/api/postback/42?key=PARTNER_SECRET&event=ftd&event_id={event_id}&click_id={click_id}&amount={payout}&currency={currency}&offer={offer_id}

Укажите адрес в исходящем S2S-постбеке трекера/сети. Замените примеры макросов {event_id}, {click_id}, {payout}, {currency}, {offer_id} на реальные макросы именно вашего источника. Их названия отличаются у разных систем. Если валюта постоянная, можно написать currency=USD.

Параметр Значение
key Секрет из карточки этого партнёра
event registration, ftd, repeat или reject
event_id Обязательный стабильный уникальный ID конверсии/транзакции
click_id ID клика, если есть; необязательно
amount Неотрицательная сумма события с точкой; по умолчанию 0
currency Три заглавные буквы, например USD; по умолчанию USD
offer ID/название оффера; необязательно

Создайте отдельное правило с нужным event для каждого типа события. Сумма события не является чистой прибылью компании. Постбеки не меняют финансовую таблицу и баланс.

При повторе одного события event_id должен оставаться прежним. Для разных повторных депозитов нужны разные ID: одного click_id недостаточно. Уже подтверждённая доставка с сочетанием партнёр + тип + ID повторно не отправляется. Разные данные под одним ID дают конфликт.

Если источник поддерживает POST, предпочтителен JSON и ключ в заголовке — секрет не включается в адрес:

curl -X POST 'https://YOUR-DOMAIN/api/postback/42' \
  -H 'Content-Type: application/json' \
  -H 'X-Postback-Key: PARTNER_SECRET' \
  -d '{"event":"ftd","event_id":"conversion-20261007-001","click_id":"click-001","amount":20,"currency":"USD","offer":"offer-1"}'

Используйте HTTPS и кодирование параметров URL для GET. Не добавляйте секретный URL в публичные ссылки партнёра. Это входящее событие трекера, а не webhook получения сообщений Telegram.

Шаг 5. Проверить событие целиком

  1. Убедитесь, что PUBLIC_URL содержит настоящий публичный HTTPS-домен.
  2. Отправьте тестовую конверсию из источника с уникальным event_id и распознанными макросами.
  3. В карточке нажмите «Обновить журнал», проверьте событие и статус «Доставлено».
  4. Проверьте нужный Telegram-чат.
  5. Повторите тот же запрос с тем же ID: после подтверждённой доставки повторного уведомления быть не должно.

Тест Telegram проверяет только бота/чат. Реальные регистрации и депозиты появятся после подключения источника. Без него сайт сам не узнаёт о депозитах в казино.

Ошибки и повторные попытки

Ситуация Что делать
Неверный токен / HTTP 401 от Telegram Проверить токен BotFather, сохранить новый
HTTP 403 от Telegram Запустить/разблокировать бота, проверить доступ к группе
Неверный чат / HTTP 400 от Telegram Проверить именно chat.id и права отправки
HTTP 429 Подождать и повторить
Таймаут / недоступность Telegram Повторить из журнала или настроить повторы у источника
HTTP 403 от сайта Проверить ID партнёра, ключ и активность аккаунта
HTTP 400 от сайта Проверить event, event_id, макросы, amount и валюту
HTTP 409 от сайта Один event_id прислан с разными данными; исправить источник
«Отключено» Уведомления или этот тип события были выключены

При ошибке доставки сайт возвращает источнику HTTP 502 и сохраняет событие. Повторите отправку из журнала либо пришлите тот же запрос. Фоновой очереди автоматических повторов нет: их настраивают у источника или выполняют вручную. При таймауте Telegram мог принять сообщение до потери ответа; повтор тогда потенциально может дать дубль. Пока идёт отправка, сайт возвращает HTTP 202; зависшую попытку можно повторить через минуту.

В журнале последние 50 событий. Подтверждённые события заново не отправляются. Если ключ раскрыт, нажмите «Сменить ключ», затем обновите URL/заголовок во всех правилах источника: старый ключ сразу перестанет работать.

5. Что проверяет главный админ

«Моя команда» показывает всех сотрудников и руководителей. «Финансы» содержит доход, вознаграждение, расходы на менеджера и чистую прибыль компании от него. В форме расходов выберите менеджера; без него расход общий. Тимлидам финансовая таблица и её API недоступны.
